# Постобработка OCR паспорта РФ

## Цель и критерий решения

Ошибка в принятом документе существенно дороже лишнего `reject`. Поэтому решение принимает документ только при согласии нескольких независимых сигналов; сомнительные случаи отклоняются с запросом на повторную съёмку.

Точка входа:

```text
python postprocess.py data/test_predictions.jsonl answers.jsonl
```

Скрипт работает на CPU, без сети и сторонних зависимостей.

## Что проверяет обработчик

Для каждого документа `postprocess.py`:

1. Извлекает все 10 полей из визуальной зоны и нормализует только регистр и пробелы.
2. Проверяет форматы пола, дат, кода подразделения и номера паспорта.
3. Проверяет действительность паспорта на 01.10.2026: минимальный возраст при выдаче, замену после 20 и 45 лет с 90-дневным сроком, а также случай рождения 29 февраля.
4. При структурно читаемой MRZ валидирует формат строк и контрольные цифры, затем сверяет с визуальной зоной номер паспорта, дату рождения, дату выдачи, пол и код подразделения.
5. Сверяет ФИО с MRZ по транслитерации, соответствующей формату внутреннего паспорта РФ.
6. Применяет пороги к минимальной символьной уверенности, а не к средней уверенности поля. Для полей, не подтверждаемых MRZ (в частности, места рождения и органа выдачи), пороги строже.
7. Дополнительно отклоняет характерные случаи неполного считывания многострочного места рождения и случаи с нестабильными коррелированными ошибками ФИО, выявленные при калибровке.

Справочник подразделений DaData использован только для анализа. Он не является источником для автоматической замены названия органа выдачи: в train есть корректные исторические значения, которых в справочнике нет.

## Калибровка и валидация

`calibrate.py` делит train детерминированно по чётности `doc_id`. Пороги и защитные правила проверялись отдельно на обеих непересекающихся частях.

| Часть train | Корректные accept | Ложные accept |
| --- | ---: | ---: |
| Чётные `doc_id` | 98 | 0 |
| Нечётные `doc_id` | 118 | 0 |
| Всего, 3 000 документов | **216 (7,2%)** | **0** |

В частности, для документов с валидной MRZ использован базовый порог 0,950; для номера паспорта и места рождения — 0,992; для наименования органа выдачи — 0,975. Документы без структурно читаемой MRZ требуют почти максимальной уверенности по всем полям.

Нулевое число ложных принятия на train не гарантирует нулевой риск на test, однако стратегия намеренно оптимизирована под стоимость ошибки из условия: она предпочитает лишний `reject` потенциально неверному `accept`.
